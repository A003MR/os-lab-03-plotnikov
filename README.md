## Что пошло не так (Troubleshooting)
В ходе выполнения работы проблем с доступом к процессам не возникло. Однако при запуске двух процессов `yes` для проверки приоритетов без использования `taskset -c 0` они могли разойтись по разным ядрам процессора, что не дало бы наглядной разницы в распределении CPU. Использование `taskset` решило эту проблему. 
При охоте на вредоносный процесс возникла сложность с поиском удаленного файла, так как по умолчанию `ls -l /proc/PID/exe` не показывает скрытые удаленные файлы без прав `sudo`.
